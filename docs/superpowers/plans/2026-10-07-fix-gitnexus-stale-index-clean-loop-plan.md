# GitNexus local-store recovery Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Stop shared-store routing from trapping omc in stale-index recovery and restore surviving wiki pages to the docs mirror.

**Architecture:** Set one shared environment constant at the subprocess boundary and in interactive/headless session environment construction. Keep the existing verdict-driven heal, adding pointer-gated garbage collection after a fresh index and metadata-gated mirror restoration at its common exit.

**Tech Stack:** Python, pytest, shell node stubs, Docker E2E with real GitNexus and Claude.

**Spec:** `docs/superpowers/specs/2026-10-07-fix-gitnexus-stale-index-clean-loop-design.md`

## Global Constraints

- `GITNEXUS_SHARED_STORE=off` overrides inherited settings; per-call `extra_env` still merges last.
- `GITNEXUS_STORAGE_PATH` / `GITNEXUS_STORAGE_ROOT` remain untouched and unsupported with omc.
- No fork or Dockerfile pin changes, shared-store adoption, new freshness reasons, argv changes to `ANALYZE_ARGS`, or changes to `_destroy`'s postcondition or watch's quiet token.
- `ToolContext` remains the only runtime subprocess/env/network boundary.
- Write and run tests red before each behavior change; missing prerequisites fail loudly, never skip. Record the expected failure, not just the exit status.
- README is generated by `.claude/skills/regenerate-readme/SKILL.md`; follow the complete recipe, never patch its output by hand.
- Run `/omc:check` after each implementation task. At the final milestone run `/omc:build` then `/omc:verify`; obey the enclosing lifecycle's bounded repair rule. Do not install omc, publish, or repair host knowledge as part of this plan.

## Review Focus

- A pointer beside an already fresh index must cause no analyze, narration, or garbage collection (Task 2).
- A failed analyze before re-registration must preserve the honest stale verdict, suppress gc, and retain watch's repeated-failure bound (Task 2).
- A successful index with stale wiki metadata must permit gc even when documentation mode still needs wiki regeneration (Task 2).
- Missing or malformed wiki metadata must prevent mirror restoration; existing mirrors must remain untouched (Task 2).
- Inherited storage override variables and caller `extra_env` must preserve their existing values/precedence while normal children and sessions receive sharing off (Task 1).
